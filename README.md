# 🎮 DX-Ball OpenGL

A simple **DX-Ball (Brick Breaker)** game built using **C++** and **OpenGL**.  
This project demonstrates basic 2D graphics programming, collision detection, and game logic using the OpenGL library.

---

## 🚀 Features
- Paddle and ball mechanics
- Brick collision and destruction
- Score tracking
- Game over and restart system
- Smooth animation using GLUT
- Modular and readable C++ code

---

## 🧩 Technologies Used
- **Language:** C++
- **Graphics Library:** OpenGL (GLUT)
- **Compiler:** Code::Blocks / Visual Studio / Dev-C++

---
